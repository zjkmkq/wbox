# 工作台总览

这个工具不是"APK 解包器"。它把一次 Android → HarmonyOS 迁移拆成**可回溯的判断链**，并且把"验证"内置在里面——你不需要记命令，也不需要靠嘴描述现象。

## 五个入口

### ① 一键流水线（最快，适合形态明确的包）
拖入 APK，工具自己判形态 → 按模板走 → 装配 → 编译 → 出 HAP 和报告。

适合：Cordova/H5 壳、远程 WebView 壳这类**模板已有定论**的形态。

不适合：第一次遇见的新形态（模板还没建立，硬跑只会产出垃圾）。

### ② 五步专家模式（可控，适合所有形态）
拆 → 画拼图 → 判断 → 填上 → 补缝。每一步都有 AI 助手，但**每个决定由你按下**（契约里 `decided_by` 永远是 human）。

第一次迁移一个新形态，走这里。

### ③ 形态诊断仪（只想先知道"能不能迁"）
只丢 APK 进去，不出工程。输出：命中的形态、判定证据、迁移步骤、已知坑、预计工作量。

**遇到没见过的包，先走这里。** 诊断结论如果指向 Unity，你就省下了三天。

### ④ 迁移知识库
形态模板 + 教程 + 真实案例。案例是带数字的（HAP 字节数、资源条数、踩过的坑），不是泛泛而谈。

跳石子、圆锯、RE 三个真实工程都在里面。

### ⑤ 排障台
所有工程的缝清单（seams）、失败记录、日志检索。迁移不是一次成功的事，这里负责"上次卡在哪"。

## 怎么选（一句话版）

- 想快速出包、且包是 H5 壳 → **一键流水线**
- 没见过这个包 → **先诊断**，再决定 ①还是②
- 需要精确控制每个资源/模块的去留 → **五步专家模式**
- 卡住了 → **排障台**，先看有没有人踩过

## 三条铁律（写在形态模板里，不是口号）

1. **先判形态，再定路径** —— 判据必须是代码级指纹（`.so` 名、assets 结构、引擎 banner），不是包名或后缀。
2. **渲染器不干预，缺啥补啥** —— 让引擎自己选渲染器；设备缺 WebGL 才在注入层补 tint。强制 Canvas 会让颜色全错。
3. **每一步都要自证** —— 编译/装机/截图/逐像素对比，全部内置。没有自证，一个颜色问题能烧一天。

## 界面怎么读

- **左栏**：资源清单（自动分类：图片/音频/字体/布局配置/代码/其它）。图片双击可预览。
- **中栏**：当前步骤的工作区。
- **右栏**：帮助中心。上面是当前步骤对应的教程，中间可以搜（先查本地，查不到再联网），下面是相关推荐。
- **顶部**：六步导航 + 保存。

右栏的记录面板在「记录」标签里，和帮助中心并排。
