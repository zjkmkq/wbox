# H5 游戏迁移实战（跳石子 Skip the Stone）

## 起点

- APK：Cordova 壳，游戏本体在 `assets/public/`
- 引擎：Phaser 4.2.1（`grep "Phaser v" assets/*.js` 确认）
- 美术：**100% 程序化生成**，`public/` 里零张图片

## 第一步：把框架噪音清掉

拆出来的 `logic_classes` 提案里全是噪音：`Bridge`、`Plugin`、`JSObject`、`$$ExternalSyntheticLambda*` —— 这些是 Capacitor 的原生插件桥，跟游戏逻辑无关。

**这些类必须清到 `draft/` 外面**（比如 `<project>/rejected/`），因为装配器递归扫 `draft/`。实测没清时：134 个残类 → 装配器注册了 7 个页面 → HAP 更大更慢。

清理后：**3 个代码文件 / 27 项资源 / 1 个页面**。

## 第二步：资源整树搬迁

H5 的资源**绝对不能扁平化**。`index.html` 里写的是 `./assets/xxx.js`，路径一乱整包白屏。

```
rawfile/
  index.html
  assets/     ← 整棵树
  wbox-bridge.js
```

**`index.html` 必须去掉 `crossorigin` 属性**。`resource://` 是不透明源，带 CORS 模式的 script 加载会全部失败，表现是白屏 + 控制台 CORS 报错。

## 第三步：页面登记（白屏第一大坑）

`module.json5` 必须是：

```json
"pages": "$profile:main_pages"
```

**不是** `routerMap`。`routerMap` 是 FA 模型的老字段，只服务 `pushNamedRoute` 的名称路由。`loadContent`/`pushUrl` 按 `pages` 解析 —— 写错了页面不挂载，系统白底，**进程还不死**（所以看起来像"卡住了"而不是"崩溃了"）。

这个坑在 RE.apk 上也出现过，是同类工程的通病。

## 第四步：桥接（只补真正缺的）

ArkWeb 没有 `androidBridge`，也没有 `webkit.messageHandlers.bridge`，所以 `isNativePlatform()` 恒为 `false`。

**好消息**：这意味着 H5 会走开发者自己写的 web 降级分支（Preferences→localStorage、Haptics→navigator.vibrate、IAP→mock）。**不要伪造原生桥**，那会让它走进不存在的 native 分支。

**只补一样**：`navigator.vibrate`。ArkWeb 自带的 vibrate 没有系统振动权限通路（调了不震），所以改成走 `javaScriptProxy` 暴露的原生 vibrator。

## 第五步：三个"看起来像 bug 但不是"的现象

### 画布空白 / 一坨蓝色
- 空画布会透出 `body{background}`（这游戏是 `#101a2e` 深蓝）
- 程序化生成像素美术在模拟器上要 **10~15 秒**
- 对策：开机遮罩 + 就绪探针（读 `window.game` 状态）+ 硬超时兜底

### 点了没反应
查 DOM 里 `position: fixed` 的高层元素。这游戏有个 `#turn` 遮罩在等条件，吞掉触摸。

### 标题糊成一片白
不是字体缺失，是 **Canvas 回落丢了 tint**。详见《无 WebGL 的渲染补偿》。

## 第六步：验证（别跳过）

```
# 1. 编译
python scripts/build_draft.py <工程> --out D:/harmony/SkipTheStone

# 2. 装机 + 截图
python scripts/verify_device.py --wait 20 --tag v1

# 3. 同一份 H5 在桌面 Chromium 跑一遍做对照
node scripts/browser_probe.js "http://127.0.0.1:8799/index.html" canvas out.png 810x366 1
```

第 3 步是分水岭：**它能 30 秒内告诉你是"H5 本身坏了"还是"ArkWeb 把它跑坏了"**。

## 最终结果

- 破解版 HAP：3,159,489 字节
- 正常版 HAP：3,159,554 字节（修复了商店扣款被改成充值的问题）
- 两版可在同一设备共存

## 缝清单（这条工程真正留下的东西）

- 切割/投掷手感需要在真机上验证（模拟器触控与真机不同）
- 无 WebGL 时的 tint bake 已补偿，但真机若有 WebGL 会走原生路径，两条路都要验
- 挂机收益（idle）在正常版里仍然生效，这是游戏自带设计，不是破解
