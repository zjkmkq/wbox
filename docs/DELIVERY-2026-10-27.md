## 五、怎么用新的工作台

1. 双击 `dist/WBox.exe`（首次启动会把内置 apktool 解到 `%LOCALAPPDATA%\WBox\tools`）。
2. 首页选路径：新手走「一键流水线」，要精细控制走「五步专家」。
3. 丢 APK 进「形态诊断仪」→ 30 秒给形态结论 + 三条铁律总纲。
4. 打开任意工程后，右侧帮助中心按当前步骤推情境教程；断网时联网区自动消失。
5. 「工具箱」一键编译/装机/巡检；缺 JDK/DevEco/hdc 时「设置 → 插件与依赖」一键装。

## 六、注意事项

- **换 exe**：旧快捷方式若指向旧 `WBox.exe`，请手动更新到新的 `dist/WBox.exe`。
- **依赖**：JDK17 / DevEco Command Line Tools / hdc 首次使用会引导安装，未装时相关按钮自动禁用。
- **联网检索**：默认开启，离线自动隐藏，设置里可关。
- **瘦身版**（74MB、联网检索降级为系统浏览器）如需，可 `WBOX_SLIM=1 pyinstaller --noconfirm --clean wbox.spec` 另打一份。
